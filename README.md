# آوانویس ۳ — نسخه آنلاین

اپلیکیشن Android با Kotlin و Jetpack Compose برای ضبط پیوسته و تبدیل گفتار فارسی به متن از طریق سرور آنلاین.

- کد این مخزن فقط برای نسخه آنلاین است و از Vosk/Whisper محلی استفاده نمی‌کند.
- صوت در قطعه‌های تقریباً ۸ ثانیه‌ای به نشانی HTTPS تنظیم‌شده در برنامه ارسال می‌شود.
- برای کارکردن تبدیل گفتار، سرور `online-server/` باید جداگانه مستقر شود و کلید سرویس‌دهنده روی سرور تنظیم شود.
- ساخت APK با GitHub Actions در شاخه `main` انجام می‌شود؛ از بخش Actions، فایل Artifact را دانلود کنید.
- شناسه برنامه `ir.avanevis.study.online` است و در کنار نسخه آفلاین نصب می‌شود.

**توجه:** این نسخه از نظر کامپایل در محیط محلی هنوز آزموده نشده است. ساخت GitHub Actions مرجع تأیید خواهد بود.
